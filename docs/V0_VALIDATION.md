# CPU Path Tracer v0 validation (macOS, 2026-11-19)

Apple Clang 17, CMake Release, single thread. No Windows execution.

Actual build/test commands:
```sh
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
ctest --test-dir build-release --output-on-failure
```
Final result: 2/2 passed (1.38 s), no compiler warnings. Initial configuration mistakenly applied warning flags to CTest utility targets; fixed by excluding UTILITY targets before building.

Actual main render commands (defaults: 256×256, seed 1, depth 16, BVH, direct on):
```sh
./build-release/path_tracer --spp 8 --output build-release/cornell-low.ppm
./build-release/path_tracer --spp 128 --output build-release/cornell-128.ppm
./build-release/path_tracer --scene point --spp 64 --output build-release/point-64.ppm
```
Measured total render/write times: 1.63157 s, 26.858 s, 18.3517 s respectively (other validation processes overlapped some runs; these are observations, not controlled benchmarks). PPM images parsed as 256×256 and converted to PNG with local Pillow solely for inspection; the renderer has no Pillow dependency. Visual inspection shows reflected rectangular lamp and walls in the mirror, transmitted background/refraction in glass, contact shadows, and red/green indirect spill. Glass/caustic noise remains visible. Point-light scene shows hard cast shadows. No claim of converged caustics.

Reproducibility commands used 48×48, 32 spp, seed 93, depth 16:
```sh
./build-release/path_tracer --width 48 --height 48 --spp 32 --seed 93 --accel bvh --output build-release/bvh-a.ppm
./build-release/path_tracer --width 48 --height 48 --spp 32 --seed 93 --accel bvh --output build-release/bvh-b.ppm
./build-release/path_tracer --width 48 --height 48 --spp 32 --seed 93 --accel linear --output build-release/linear.ppm
./build-release/normal_preview --width 320 --height 180 --output build-release/normal-regression.ppm
```
First three files byte-identical (0.354352, 0.375431, 0.290010 s). Normal regression byte-identical to existing build/normal.ppm; old file preserved. Tiny scene BVH was not faster than linear in this run. Invalid zero spp, negative seed, nonnumeric depth, unknown scene/accel/direct, missing width and existing output were all rejected with exit 1.

Direct-sampling comparison: eight actual commands generated by substituting seed=1..4 and mode=on/off:
```sh
./build-release/path_tracer --width 32 --height 32 --spp 4096 --depth 16 --seed SEED --direct MODE --output build-release/compare-SEED-MODE.ppm
```
All statistics below are BEFORE display conversion, using luminance 0.2126 R + 0.7152 G + 0.0722 B. Raw command/output evidence: build-release/comparison.json (ignored local artifact).

- on: mean 0.33852309, sample standard deviation across four seeds 0.00052500.
- off: mean 0.33866495, sample standard deviation across four seeds 0.00024151.
- Paired on−off mean: -0.00014186; estimated standard error 0.00033643.

No large systematic double-brightening observed. Four seeds and whole-image means cannot prove unbiasedness or exclude local errors; finite depth truncation is biased and differs slightly at the final direct-light event. Pure BSDF mode has greater local variance. Point lights cannot be evaluated by pure BSDF hits, so this comparison uses the Cornell area light only.
