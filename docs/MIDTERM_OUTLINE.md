## 目标与当前实现

Forest Creek Cabin：森林冷光、木屋暖窗、弯曲溪流和自然岸线的静态图像。当前 v0.5 是可运行 CPU 路径追踪器与明显低多边形主视觉。C++17/CMake、基础材质、BVH、点/面光、原创纹理/OBJ、相机效果、alpha、HDR/MIS和确定性多线程已有代码/测试与 Mac 证据；实现清单见 REQUIREMENTS_STATUS，不能等同课程得分。

## 建议两页结构与图片

1. 目标、技术路线和主视觉：v05-color/v05-detail，解释 v04→v05 的木纹、岸石、树群调整；V05_VALIDATION 保存参数、15,593 三角形及耗时。
2. 方法与验证：选 Cornell 展示漫反射/镜面/理想玻璃；合成一组景深/运动/alpha 小对照，引用 V02 的时间与层透射测试，而非仅凭外观声称正确。
3. 采样实验：V04_VALIDATION 中八 seed 线性 RGB RMSE（BSDF .07508、NEE .02818、MIS .02757）及参考噪声 .00312；MIS 相对 NEE收益仅约 2.1%，不是所有场景普遍更好。可选用这组替换部分效果小图，避免两页塞满。
4. 性能与限制：V03 的同场景 1/4 线程 24.36/7.75 秒仅适用于当时场景参数；V01 的 BVH/线性证据另有场景，不把它们当作 v05 性能。新展示包 manifest 适合现场复现，不替代受控实验。

优先 3–4 组图片：主视觉、Cornell、相机/alpha 对照拼图、采样误差图表。PNG 可从已有预览或 PPM 经可选 Pillow转换取得；先验证文件与命令出处，不填造图号/贡献。

## 限制及剩余工作

Windows 队友验证待反馈；画质低多边形、地表/树冠/天空仍简单；材质为 Lambertian/理想镜面/理想介质，OBJ 仅三角面/指定材质/平面着色，无完整 MTL；HDR 输入仅 PFM，最近邻纹理；有限深度有偏差、亮源和焦散仍有噪声。MIS/HDR有实现证据，不能直接宣称已获选做分。
